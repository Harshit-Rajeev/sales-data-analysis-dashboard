# Sales Data Analysis & Interactive Dashboard

## 📊 Project Overview

This project focuses on analyzing sales data using **Python, SQL, and Power BI**. The objective was to clean and transform raw sales data, perform analytical queries, and build an interactive dashboard to identify important business insights.

## 🛠️ Technologies Used

* **Python** – Data cleaning and preprocessing
* **SQL** – Data manipulation and analysis
* **Power BI** – Interactive dashboard and data visualization

## 🔍 Key Analysis

* Sales and revenue performance
* Product performance
* Profit analysis
* Sales trends
* Key performance indicators (KPIs)

## 📈 Power BI Dashboard

The interactive dashboard includes charts, KPIs, slicers, and filters to allow users to explore sales performance and identify trends.

## 📁 Project Structure

* `data/` – Dataset used for analysis
* `python/` – Python data cleaning and analysis scripts
* `sql/` – SQL queries used for analysis
* `powerbi/` – Power BI dashboard
* `screenshots/` – Dashboard screenshots

## 🎯 Key Learning

This project provided practical experience in **data cleaning, SQL analysis, data visualization, and interactive dashboard development** using industry-relevant tools.
